Agenda Pokémon - Poké Fight v1.2  (recompilation for Windows 10/11)
====================================================================

Run PokeFight.exe. No installation needed.

The "data" folder must stay next to PokeFight.exe: it holds the Pokémon
images (000.gif to 151.gif), the stat bars (1.gif to 6.gif) and the
interface images (data\ui).

Settings (theme, effects, colors) are stored in %APPDATA%\PokeFightAgenda\agenda.ini.

Hidden shortcut: Ctrl+Shift+P shows the "Personagens" (Characters) button,
which existed in the original program but was never displayed (Ash, Brock,
Misty, Oak, Team Rocket, Gary).

The program is in Brazilian Portuguese, as in the original release.
